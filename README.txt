ANKITA MADAM — A LITTLE SMILE WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Open index.html in a browser to preview.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html, style.css, script.js and the complete assets folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for the published link to appear in Settings > Pages.

To change the photo, replace assets/ankita-photo.png with another image using the same filename.
The page uses Google Fonts when internet is available; it still works without them using fallback fonts.
